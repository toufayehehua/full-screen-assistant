# Full-Screen Assistant

让网页视频单独全屏播放，同时继续浏览其他网页。

点击网站播放器的全屏按钮，视频会在独立窗口中全屏播放。你仍可使用原网站的播放按钮、字幕、弹幕和清晰度设置，原浏览器里的其他网页也能继续使用。

## 安装

适用于电脑上的 Chrome 120 或更新版本。

1. [下载插件压缩包](releases/Full-Screen-Assistant-0.2.1-build11.zip)并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的文件夹。
4. 刷新视频网页，再点击播放器的全屏按钮。

也可以下载本项目源码，选择项目根目录安装。

## 怎么用

- **进入全屏**：点击网站播放器的全屏按钮；也可以点击浏览器工具栏里的插件图标。
- **继续浏览**：切回原浏览器，使用其他网页。
- **返回原位置**：按 Esc、点击播放器的退出全屏按钮，或点击原浏览器中的视频占位页。再次点击插件图标也可返回。

**关闭视频窗口或按 Cmd+W 会关闭视频网页。想保留视频，请使用上面的返回方式。**

## 需要了解

- 视频原来的整张网页会一起移到独立窗口，返回后才能在原浏览器里继续操作这张网页；其他网页不受影响。
- 不同网站的播放器可能表现不同，尚不能保证所有视频网站都能正常使用。
- Chrome 设置页、Chrome 网上应用店和本地文件页面不支持此插件。
- 重新加载、停用或卸载插件前，请先退出独立全屏。

## 隐私

视频仍由原网站播放。插件不会上传网页地址、页面标题或视频预览图。

为方便退出全屏或后退，插件会在本机暂存返回位置和原网页地址；占位页的浏览器历史记录会保留原网页地址，直到浏览器移除该记录或你清理历史。详见[隐私政策](store/privacy-policy.html)。
